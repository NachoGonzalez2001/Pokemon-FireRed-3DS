Build Pokémon FireRed 3DS

Turn your own Pokémon FireRed ROM into a ready-to-copy installation for your Nintendo 3DS. Version: …

Your ROM is processed entirely in your browser and never leaves your device. Nothing is uploaded: the game data is created on this device by the project's own builder.

1. Choose your ROM

Pokémon FireRed (USA, Rev 1): a .gba file, or a .zip with one inside.

The first build downloads the builder (about 25 MB, kept by your browser for later) and takes a few minutes. Keep this tab open while it works.

Download the ZIP

Copy it to your SD card

  1. Extract the ZIP. It has one folder, 3ds.
  2. Copy that 3ds folder to the root of your SD card and merge it with the one there. Your save, firered3ds.sav, is not in the ZIP and is not touched.
  3. Make sure sd:/3ds/dspfirm.cdc is there (for sound).
  4. Start Pokémon FireRed 3DS from the Homebrew Launcher.

Optional: a HOME Menu icon

Install the forwarder once with FBI: Remote Install → Scan QR Code. It opens the game installed in sd:/3ds/firered3ds/, so later updates never need it again.
